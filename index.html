Arsitektur yang benar: Starlink → MikroTik (Hotspot + User Manager) → Access Point → Pengguna. MikroTik yang memutus otomatis saat waktu voucher habis. Aplikasi ini membuat voucher lalu mengirimkannya ke MikroTik.

Ekspor ke MikroTik (cara paling andal)

Buat skrip perintah dari voucher belum terpakai. Salin/unduh, lalu tempel di Terminal MikroTik (Winbox → New Terminal). Pengguna hotspot langsung dibuat dengan batas waktu — MikroTik otomatis memutus saat habis.

Klik "Buat Skrip" untuk menghasilkan perintah…

Sambungan Langsung (opsional, tingkat lanjut)

Kirim voucher langsung ke MikroTik lewat REST API (RouterOS v7). Perlu API aktif dan biasanya halaman ini dihosting di jaringan yang sama atau lewat proxy — karena keamanan browser (CORS) sering memblokir. Kalau gagal, pakai ekspor .rsc di atas.

Butuh bantuan pasang? Bilang saja — saya bisa buatkan panduan langkah demi langkah setting MikroTik Hotspot + User Manager (mode bridge Starlink, profil kecepatan, halaman login/captive portal), atau proxy kecil supaya sambungan langsung bekerja.
